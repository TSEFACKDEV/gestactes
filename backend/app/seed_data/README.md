# Données de démonstration

Ce dossier contient les pièces justificatives et les PDF d'actes
utilisés par `app/seed.py`. Les fichiers sont générés par
`scripts/generate-demo-assets.py` et versionnés pour que chaque clone
du projet retrouve les mêmes documents, sans dépendre de GitHub.

Aucune donnée personnelle réelle n'est utilisée.
